# Пепел Королевства v30.7 — Ultimate Juice, Filters, Haptics & Citadel Alerts Edition

Мобильная offline-first RPG/PWA. Версия 30.7 объединяет обратную связь в бою, безопасную вибрацию, фильтры инвентаря, сравнение экипировки, звуковые сигналы редкой добычи, ауру Кармы/Скверны и индикаторы Цитадели.

## Основные изменения
- Тряска ограничена `.combat-container`; критические попадания, промахи и тяжёлые удары не трясут всю страницу.
- `triggerHaptic()` безопасно проверяет поддержку `navigator.vibrate` и используется для действий и редкой добычи.
- Инвентарь фильтруется по всем предметам, оружию, броне и припасам; окно предмета создаётся динамически непосредственно в `document.body`.
- Сравнение экипировки показывает разницу атаки и защиты; редкие предметы получают отдельный Web Audio сигнал.
- Карма и Скверна влияют на свечение панели баланса и профиля.
- Точка Цитадели сообщает о пассивном доходе и доступных улучшениях; недоступные рецепты/кузнечные действия приглушены.
- Мобильная область фиксирована по viewport; прокрутка остаётся внутри игровых панелей и списков.
- Версии CSS/JS и кеша Service Worker обновлены до `30.7`.

## Запуск
Открой `index.html` для локального просмотра. Для установки PWA и офлайн-кеша используй HTTPS-хостинг, например GitHub Pages.

`index.html`, `style.css`, `database.js`, `game.js`, `manifest.json`, `sw.js`, `assets/icon.svg`.
