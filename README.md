# Пепел Королевства — v33.0

Intelligent & Brutal Enemies Overhaul. Обновлены стойки врагов (Aggressive/Defensive/Parry), предупреждение о сокрушительном выпаде, уязвимости/сопротивления, берсерк при HP ниже 35%, кровотечение и защитное действие. Сохранены существующие игровые системы и мобильный интерфейс v32.2.

Публикация: загрузить содержимое этой папки в корень репозитория GitHub Pages, включая `sw.js`, `database.js`, `game.js`, `style.css`, `index.html`, `manifest.json` и `assets/`.

Статическая проверка синтаксиса выполнена отдельно; запуск в браузере и игровой баланс на устройстве требуют ручного тестирования.
