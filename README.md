# Пепел Королевства — PWA Rune Edition

Текстовая Dark Fantasy RPG с SVG-иконографикой, адаптивной мобильной раскладкой, автосохранением и офлайн-кэшем PWA.

## Файлы
- `index.html` — интерфейс и метаданные PWA.
- `style.css` — адаптивные стили, кастомные элементы управления и анимации.
- `database.js` — контент игры.
- `game.js` — игровой цикл, бои, инвентарь, сохранения, смена фаз.
- `manifest.json` — параметры установки.
- `sw.js` — Service Worker для кэширования и запуска офлайн.
- `assets/` — SVG-спрайт и иконки приложения.

## Запуск и установка
Service Worker работает только на `https://` или `localhost`; просто открыть HTML как `file://` недостаточно. Загрузите **все файлы и папку assets целиком** в репозиторий GitHub и включите GitHub Pages.

- **iPhone/iPad (Safari):** откройте опубликованный HTTPS-адрес → «Поделиться» → «На экран Домой».
- **Android (Chrome):** откройте HTTPS-адрес и используйте «Установить приложение»/«Добавить на главный экран».
- **ПК:** Chrome/Edge могут показать кнопку установки в интерфейсе сайта.

После первого успешного открытия основные файлы кэшируются и игра может загружаться без сети. Сохранение прогресса хранится локально в браузере на конкретном устройстве. Для обновления кэша версия указана в `CACHE_NAME` в `sw.js`.

## Проверки
Синтаксис JavaScript проверен через `node --check`; файлы PWA и ссылки ресурсов проверены на наличие. Полноценный запуск в браузерном движке и установка на реальные устройства требуют публикации по HTTPS.
