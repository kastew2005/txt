# Пепел Королевства v30.4

## Modal DOM Architecture & Blur Separation Fix

- `#modal` и `#item-action-modal` находятся непосредственно в `<body>`, вне `#app`.
- CSS blur применяется к затемняющему слою, а не к содержимому модального окна.
- Резервная защита в `game.js` переносит корни модальных окон в `document.body`, если старый HTML всё ещё вкладывает их в приложение.
- Подключения используют `?v=30.4`; Service Worker обновлён до `cache-v30.4`.

Для публикации замените файлы репозитория содержимым папки `project` и опубликуйте изменения. Проверены синтаксис JS и структура файлов; полноценный запуск в мобильном Safari не выполнялся.
