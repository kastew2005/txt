# Пепел Королевства v31.1 — Robust Auto-Save & Persistence System

- Версионированное сохранение в localStorage (`ashes_kingdom_save_v1`) с временной меткой.
- Загрузка поддерживает предыдущие сохранения без поля версии; несовместимая более новая major-версия отклоняется.
- Автосохранение каждые 30 секунд, при завершении боя/отступлении, смене узла карты, действиях с предметами и скрытии/закрытии страницы.
- В меню «Ещё» добавлены «Сохранить игру» и «Сбросить прогресс / Новая игра» с подтверждением.
- Ресурсы и кеш Service Worker обновлены до v31.1.

Загрузите все файлы проекта на GitHub Pages. Полный игровой тест в мобильном Safari не проводился; выполнены статические проверки синтаксиса и структуры.
