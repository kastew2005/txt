# Пепел Королевства — v16.0 Master Edition + QoL Polish

Мобильная PWA Dark Fantasy RPG без внешних библиотек и внешних изображений. Иллюстрации интерфейса строятся локальными SVG и CSS.

## Запуск

Загрузи всё содержимое этой папки на HTTPS-хостинг (например, GitHub Pages), сохранив структуру `assets/`. Для установки Service Worker нужен HTTPS (или localhost). После первого онлайн-открытия приложение кэширует основные файлы и затем может запускаться офлайн.

## Управление сохранениями

Экспорт AK16 использует XOR-маскировку, Base64 и контрольную сумму для обнаружения повреждения кода. Это не криптографическое шифрование и не защита от мотивированного редактирования: ключ находится в клиентском JavaScript. Поддержан импорт форматов AK15 и AK14.

## Проверки

Проверяйте JavaScript синтаксисом `node --check`, JSON через `python -m json.tool`, а затем протестируйте игру в браузере и на целевом iPhone. Вибрация зависит от поддержки `navigator.vibrate`; iOS Safari может её игнорировать.
