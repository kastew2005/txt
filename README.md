# Пепел Королевства v10.0

Браузерная Dark Fantasy RPG с пошаговым боем, интерактивной картой выбора маршрута, меню дополнительных разделов и четырёхшаговым обучением.

## Запуск
Откройте `index.html` в современном браузере или опубликуйте всю папку на GitHub Pages. Для установки как PWA используйте HTTPS.

## Обновление
Загружайте весь проект целиком, включая `database.js`, `manifest.json`, `sw.js` и каталог `assets`. Service Worker использует новый cache ID v10.0.

## Основные исправления v10.0
- Добавлена отсутствовавшая отрисовка арены боя и синхронизация кнопок с состояниями боя.
- Явные состояния `state.inCombat`, `state.turn` и `state.combatBusy`; атака, ярость, зелья и заклинания не могут выполняться в чужой ход.
- Карта сначала выбирает локацию, показывает подсвеченный маршрут, а перемещение запускается кнопкой «Отправиться в путь».
- Меню «Ещё» ведёт в таверну, навыки, спутников, подземелья и алхимию/руны.
- Сохранено четырёхшаговое обучение с возможностью пропуска.
