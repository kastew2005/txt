# Пепел Королевства v9.5 — UX Scale & Layout Redesign

Обновление интерфейса поверх v7.0 «Живые легенды и карта путешествий».

## Что изменено
- Нижняя навигация сокращена до пяти крупных кнопок: Мир, Бой, Цитадель, Герой, Ещё.
- Таверна, Навыки, Спутники, Подземелье и Алхимия открываются через модальное меню «Ещё».
- Инвентарь и профиль собраны в раздел «Герой»; из инвентаря есть быстрый переход в профиль.
- Убрана боковая панель характеристик, занимающая полезную ширину. Краткие HP/золото/уровень/карма остаются в шапке, подробные характеристики — в профиле и сводке экипировки.
- Увеличены размеры текста, иконок, кнопок и интерактивных узлов карты.
- Добавлены безопасные отступы iOS и сохранён фиксированный экран с внутренней прокруткой длинных вкладок.
- Обновлён cache ID Service Worker, чтобы браузер загрузил новую версию CSS/JS.

## Запуск
Разместите файлы из папки проекта на HTTPS-хостинге (например, GitHub Pages). Для офлайн-работы откройте игру онлайн один раз, чтобы Service Worker сохранил основные ресурсы. На iPhone откройте опубликованный адрес в Safari → «Поделиться» → «На экран Домой».

## Проверки
Проверены синтаксис `game.js`, `database.js`, `sw.js`, JSON манифеста и структура архива. Полный ручной игровой тест на физическом iPhone не выполнялся.


## v9.5 — Critical Click Fix & Interactive Tutorial
- Делегирование кликов на уровне document для навигации, карты и динамических действий.
- Погодные и декоративные слои исключены из hit-testing через pointer-events: none.
- Добавлено интерактивное обучение из четырёх шагов с пропуском и сохранением tutorial_passed в localStorage.
- Service Worker cache обновлён для принудительного обновления ресурсов.
