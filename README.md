# Пепел Королевства v34.2

Расширенная карта с четырьмя регионами, gates по уровню/боссу/постройке, масштабирование характеристик противников по регионам, элитные свойства врагов, теги особенностей, сохранения localStorage и Combat Lock.

Файлы: index.html, style.css, database.js, game.js, sw.js, manifest.json.

Публикация: загрузите содержимое этой папки в корень репозитория GitHub Pages. Реальный запуск в браузере/на iPhone нужно проверить после публикации.
