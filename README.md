# Пепел Королевства v30.6 — Radical Modal DOM Re-injection & Blur Annihilation

Мобильная офлайн Dark Fantasy RPG PWA.

## Изменения v30.6
- Окно предмета создаётся динамически функцией `showItemModal(item)` как новый `#rad-modal-root`, добавленный непосредственно в `document.body`.
- Перед открытием удаляется старый динамический корень, а старый статический item modal удалён из HTML.
- Инлайн-стили закрепляют непрозрачную карточку и отключают фильтры/размытие на оверлее и содержимом.
- Глобально отключены `backdrop-filter` и `-webkit-backdrop-filter`, как предусмотрено спецификацией v30.6.
- Сохранены действия предметов: надеть/снять, использовать, продать, выбросить; закрытие по кнопке, нажатию на фон и Escape.
- Обновлены ресурсные версии и Service Worker до `v30.6` / `cache-v30.6`.

## Запуск
Открой `index.html`. Для установки PWA и офлайн-кеша опубликуй проект через HTTPS, например GitHub Pages.

## Файлы
`index.html`, `style.css`, `database.js`, `game.js`, `manifest.json`, `sw.js`, `assets/icon.svg`.
