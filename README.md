# Пепел Королевства — v30.0: Ultimate Progression, Skill Tree & Endless Abyss

Офлайн PWA на HTML/CSS/JavaScript. В сборке сохранены исходные боевые механики, карта, инвентарь, Цитадель, крафт и синтезатор Web Audio API.

## Новые системы v30.0
- **Дерево талантов:** Путь Крови, Путь Тьмы и Путь Выживания; каждый ранг тратит одно очко навыка, получаемое за уровень. Таланты сохраняются.
- **Бесконечная Бездна:** этажи повышают HP, атаку и защиту врагов; каждый пятый этаж создаёт элитного фазового босса. Шанс редкого лута и рун растёт с глубиной.
- **Бестиарий:** победы записываются по типам врагов; на 5/15/30 побед открываются постоянные бонусы урона против соответствующего типа.
- **Наследие и хардкор:** режим перманентной смерти включается перед созданием героя. После гибели опыт и золото конвертируются в осколки душ; улучшения наследника сохраняются между забегами.
- **Web Audio SFX:** синтезированные звуки талантов, победы в Бездне, открытия записи Бестиария, атак и монет; внешние аудиофайлы не требуются.

## Проверки
- `node --check game.js`, `node --check database.js`, `node --check sw.js`.
- `manifest.json` проверен как JSON.
- База данных выполнена в Node VM и проверены наличие шести талантов, двух событий и семи рецептов.
- Полноценное прохождение на iPhone не выполнялось; перед релизом проверьте запуск в мобильном браузере.
