# Пепел Королевства v30.5

## Modal Blur Isolation & High Contrast Overhaul

- Размытие применяется только к фоновому оверлею модального окна, а не к `body`, `#app` или `.main-container`.
- Модальные корни остаются прямыми потомками `body`, вне игрового контейнера.
- Карточка модального окна имеет плотный фиолетово-серый фон `#2a2342`, светлую рамку и высококонтрастный текст/кнопки.
- `game.js` синхронизирует класс `body.modal-open` с состоянием модалок, но сам этот класс не включает блюр.
- Версия ресурсов и Service Worker обновлена на `v30.5` / `cache-v30.5`.

Для публикации замените файлы репозитория содержимым папки `project`. Проверки синтаксиса и структуры выполняются отдельно; полноценный запуск в мобильном Safari не подтверждён.
