# Пепел Королевства — Master Edition — Dark Fantasy & Tactical Combat v14.0

Однопользовательская браузерная RPG на Vanilla JavaScript, HTML и CSS. Все иллюстрации интерфейса выполнены встроенным SVG/CSS; внешние библиотеки, шрифты, изображения и сетевые API не требуются.

## Файлы
- `index.html` — интерфейс и SVG-карта.
- `style.css` — оформление, адаптивная вёрстка, эффекты и onboarding.
- `database.js` — локальные данные мира, предметов, врагов и квестов.
- `game.js` — игровая логика, бой, карта, сохранения и обучение.
- `manifest.json` — PWA manifest.
- `sw.js` — кэширование приложения для офлайн-запуска после первой загрузки.
- `assets/` — локальные SVG-иконки.

## Запуск и офлайн
Для корректной работы PWA открой проект через локальный HTTP-сервер или опубликуй на HTTPS (например, GitHub Pages). При первой загрузке Service Worker сохраняет все основные файлы; после успешного кэширования приложение открывается офлайн. Браузеры не разрешают Service Worker при прямом открытии `file://`.

## Сохранения
Игра автоматически сохраняется в `localStorage`. В нижней кнопке «Ещё» доступны «Сохранения»: экспорт JSON, копирование, импорт и сброс. Сохранение привязано к браузеру и устройству, пока не экспортировано вручную.
